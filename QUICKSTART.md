# 🤖 Быстрый запуск Telegram-бота

## 🚀 Простой способ

### Windows
1. Откройте папку `bot/`
2. Запустите `start.bat` (двойной клик)
3. Готово! Бот запущен

### macOS / Linux
1. Откройте терминал в папке `bot/`
2. Выполните команды:
```bash
chmod +x start.sh
./start.sh
```
3. Готово! Бот запущен

## 📱 Использование

1. Откройте Telegram
2. Найдите [@pd_circles_bot](https://t.me/pd_circles_bot)
3. Нажмите **Start** или отправьте `/start`
4. Нажимайте кнопки меню для навигации

## 🎯 Основные команды

- `/start` — Приветствие и меню
- `/help` — Справка
- `/menu` — Главное меню

## 🔧 Ручной запуск

Если скрипты не работают:

```bash
cd bot
npm install
node server.js
```

## ❓ Проблемы

### "BOT_TOKEN не найден"
Проверьте файл `bot/.env` — токен должен быть там.

### Бот не отвечает
- Убедитесь, что скрипт запущен (не закрыли окно терминала)
- Проверьте интернет-соединение
- Убедитесь, что токен правильный

### Mini App не открывается
- Убедитесь, что URL в `.env` правильный
- URL должен быть HTTPS
