# 🛠️ Настройка бота в @BotFather

## Пошаговая инструкция

### 1. Откройте @BotFather в Telegram
https://t.me/BotFather

### 2. Создайте нового бота (если ещё не создан)
```
/newbot
```
Следуйте инструкциям, выберите имя и username для бота.
Вы получите токен — сохраните его!

### 3. Настройте Mini App
```
/mybots → Выберите вашего бота → Bot Settings → Menu Button → Configure Menu Button
```

Введите URL вашего приложения:
```
https://2fb4378.arena.site
```

Название кнопки:
```
📚 Открыть дневник
```

### 4. Настройте команды бота
```
/mybots → Выберите бота → Edit Bot → Edit Commands
```

Введите команды (каждая с новой строки):
```
start - Запустить бота
help - Помощь
menu - Главное меню
```

### 5. Описание бота
```
/mybots → Выберите бота → Edit Bot → Edit Description
```

Текст:
```
🎓 Личный дневник ДЗ и ГДЗ

Управляй домашними заданиями, расписанием и готовыми решениями прямо в Telegram!

Команды:
/start - Начать
/help - Помощь
```

### 6. About
```
/mybots → Выберите бота → Edit Bot → Edit About
```

Текст:
```
📚 ДЗ и ГДЗ - твой помощник в учёбе!

✨ Возможности:
• Домашние задания и решения
• Расписание занятий
• Поиск по предметам
• Фото и видео вложения
• Резервное копирование

Открой Mini App и начни учиться эффективно! 🚀
```

## 🎨 Настройка бота (опционально)

```
/mybots → Выберите бота → Edit Bot → Edit Botpic
```

### Настроить имя бота
```
/mybots → Выберите бота → Edit Bot → Edit Name
```

## 🐛 Если что-то не работает

### Проблема: Бот не отвечает
**Решение:**
- Убедитесь, что сервер запущен: `node bot/server.js`
- Проверьте токен в `bot/.env`
- Проверьте интернет-соединение

### Проблема: Mini App не открывается
**Решение:**
- Проверьте, что URL в @BotFather правильный
- URL должен использовать HTTPS
- Убедитесь, что приложение доступно по этому URL

### Проблема: Кнопка Menu Button не появляется
**Решение:**
- Обновите Telegram до последней версии
- Перезапустите бота: `/start`
- Проверьте настройки в @BotFather

## 🌟 Продвинутые настройки

### Inline Mode (поиск через @username)
```
/mybots → Выберите бота → Bot Settings → Inline Mode → Enable
```

### Payments (если нужна оплата)
```
/mybots → Выберите бота → Bot Settings → Payments
```

## 📊 Статистика бота

В @BotFather доступны команды:
- `/token` — получить токен
- `/mybots` — список ваших ботов
- `/setuserpic` — установить аватар бота
- `/setname` — изменить имя бота
- `/setdescription` — изменить описание
