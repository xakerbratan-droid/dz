# 🤖 Настройка бота для работы в группах

## ⚠️ Важно: Настройка в @BotFather

Для корректной работы бота в группах необходимо выполнить несколько настроек в @BotFather.

## Шаг 1: Настройка Privacy Mode

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/mybots`
3. Выберите вашего бота: `@pd_circles_bot`
4. Нажмите **Bot Settings**
5. Нажмите **Group Privacy**
6. Выберите **Turn off**

> **Зачем:** По умолчанию бот в группе видит только сообщения, начинающиеся с `/` или упоминающие бота. Отключение Privacy Mode позволяет боту видеть все сообщения и реагировать на кнопки.

## Шаг 2: Настройка Menu Button (глобально)

1. В @BotFather нажмите **Bot Settings**
2. Нажмите **Menu Button**
3. Нажмите **Configure menu button**
4. Введите название кнопки: `📚 Дневник`
5. Введите URL: `https://2fb4378.arena.site`
6. Подтвердите

> **Зачем:** Menu Button появляется внизу экрана (рядом с полем ввода) и позволяет открыть Mini App одним нажатием. Это работает в ЛС и в группах.

## Шаг 3: Настройка Inline Mode (опционально)

1. В @BotFather нажмите **Bot Settings**
2. Нажмите **Inline Mode**
3. Выберите **Turn on**

> **Зачем:** Позволяет использовать бота через `@pd_circles_bot` в любом чате, даже без добавления бота.

## Шаг 4: Настройка команд

1. В @BotFather нажмите **Edit Commands**
2. Введите команды (каждая с новой строки):

```
start - Запустить бота / открыть дневник
help - Помощь по боту
dnevnik - Открыть дневник
rasp - Открыть расписание
```

## Шаг 5: Разрешить добавление в группы

1. В @BotFather нажмите **Bot Settings**
2. Нажмите **Allow Groups?**
3. Выберите **Turn on**

## ✅ Проверка работы в группе

1. Добавьте бота `@pd_circles_bot` в группу
2. Бот должен автоматически отправить приветственное сообщение с кнопками
3. Нажмите кнопку **«📚 Открыть дневник»** — должен открыться Mini App
4. Menu Button (📚 Дневник) должен быть виден внизу экрана у всех участников

## 🔧 Если кнопки не появляются

### Проблема: Menu Button не виден в группе
**Решение:**
- Убедитесь, что Privacy Mode выключен (Шаг 1)
- Убедитесь, что Menu Button настроена (Шаг 2)
- Перезапустите бота: `/start`

### Проблема: Бот не отвечает в группе
**Решение:**
- Проверьте, что Privacy Mode выключен
- Убедитесь, что бот имеет права на отправку сообщений в группе
- Проверьте, что бот не заблокирован в группе

### Проблема: Mini App не открывается
**Решение:**
- Проверьте, что URL в Menu Button правильный и использует HTTPS
- Убедитесь, что приложение доступно по указанному URL
- Проверьте консоль браузера на ошибки

## 📱 Как это выглядит для пользователей

### В личных сообщениях:
- Полная клавиатура с кнопками внизу
- Menu Button рядом с полем ввода

### В группах:
- Menu Button рядом с полем ввода (доступна всем)
- Inline клавиатура с кнопками под сообщениями бота
- Команды работают через `/команда@pd_circles_bot`
