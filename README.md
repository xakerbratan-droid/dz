# 🤖 Telegram Бот ДЗ и ГДЗ

Полноценный Telegram-бот с Mini App для управления домашними заданиями.

## 🚀 Запуск бота

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск бота

```bash
node bot/server.js
```

Бот запустится и будет работать в режиме polling. Вы увидите сообщение:
```
✅ Бот запущен!
📡 Telegram: @pd_circles_bot
🌐 Web App: https://2fb4378.arena.site
💻 API: http://localhost:3000
```

### 3. Использование

В Telegram откройте [@pd_circles_bot](https://t.me/pd_circles_bot) и отправьте `/start`.

Бот предложит кнопки:
- **📚 Открыть дневник** — открывает Mini App с дневником
- **📋 Расписание** — открывает вкладку расписания
- **🔍 Поиск** — открывает поиск по заданиям
- **❓ Помощь** — справка по командам
- **📖 О боте** — информация о боте

## 📦 Деплой

### Локальный запуск

```bash
node bot/server.js
```

### Продакшн (с PM2)

```bash

pm2 start bot/server.js --name "dz-bot"

```

Просто задеплойте проект, бот автоматически запустится.

## 🆘 Решение проблем

### Бот не отвечает

1. Проверьте, что токен правильный
2. Убедитесь, что сервер запущен: `node bot/server.js`
3. Проверьте интернет-соединение

### Mini App не открывается

1. Убедитесь, что URL в `.env` правильный и использует HTTPS
2. Проверьте, что приложение доступно по этому URL
3. В @BotFather настройте Menu Button → Web App URL
